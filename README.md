# Flask Portfolio Website

## Overview
This is a simple Portfolio Website built using Flask, HTML, and CSS. It displays personal information and includes a contact form for visitors.

## Features
- Personal portfolio homepage
- About Me section
- Contact form
- Simple and responsive design
- Built with Flask framework

## Technologies Used
- Python
- Flask
- HTML
- CSS
